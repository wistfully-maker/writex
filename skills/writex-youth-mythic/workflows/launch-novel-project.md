# Launch Novel Project

Use this workflow when starting a publishable novel, not when generating an isolated writing sample.

## Step 1 — Position
Resolve:
- platform / channel;
- target audience;
- genre / subgenre;
- target length;
- core reading promise;
- first-three-chapter promise.

If current platform rules or trends are material, verify them before finalizing.

## Step 2 — Project seed
Generate multiple viable seeds if needed.

Evaluate:
- one-sentence clarity;
- long-form runway;
- character/relationship depth;
- type payoff;
- differentiation;
- ability to support a full book architecture.

Do not draft chapters yet.

## Step 3 — NovelProjectCanon v0.1
Create:
`templates/novel-project-canon.yaml`

## Step 4 — Whole-book architecture
Run:
- WriteX Base long-form;
- 7A Reader Drive;
- 7B Character Magnetism;
- 7C Relationship Tension;
- 7D Type Pleasure;
- 7E Emotional Orchestration;
- 7G Ensemble Character Life.

Produce:
- book four-phase structure;
- volume blueprints;
- cross-volume handoffs;
- truth ceilings;
- reader-question ledger;
- character-life arcs;
- ending contract;
- current-volume detailed plan.

## Step 5 — Architecture audit
Run:
- base continuity / longform audit;
- enhancement audit;
- character-life audit.

Status becomes:
`BOOK_ARCHITECTURE_READY`.

## Step 6 — Human approval
Show the architecture to the user.

Only explicit approval changes state to:
`HUMAN_ARCHITECTURE_APPROVED`.

## Step 7 — Draft
Enter rolling horizon and chapter workflow.

## Step 8 — Publication package
Once core positioning and opening are stable, produce:
- title;
- synopsis;
- tags;
- editor pitch;
- launch copy.

## Step 9 — Visual handoff
Produce visual bible and briefs.

If an external visual skill is available, hand off the brief rather than re-implementing its design system.

## Step 10 — Release consistency audit
Check:
- cover promise matches prose;
- synopsis matches actual opening;
- tags match actual book;
- current canon version matches all launch assets.
