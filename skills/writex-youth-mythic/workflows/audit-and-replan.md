# Enhanced Audit & Replan

Run the Base continuity / long-range audit first.

Then run six enhancement audits:

## Reader Drive
- Are questions being paid or only planted?
- Is this volume moving toward local closure?
- Are external and private pressure curves converging?

## Character Magnetism
- Has each major character gained a new dimension recently?
- Has power/status accidentally solved the private deficit?
- Do supporting characters still have independent agency?

## Relationship
- Have important relationships changed state?
- Are we looping on cheap misunderstanding?
- Are sacrifices and boundary violations still present in the ledger?
- Did any repair pay a real cost?

## Type Pleasure
- Are mysteries narrowing?
- Did reveals change action/relationships?
- Are competence/power payoffs costed?
- Is worldbuilding operational?

## Emotional Orchestration
- Is grief earned by deposits?
- Are impact and release being confused?
- Has a major event left residue?
- Are all characters using the same defense/release behavior?

## Prose / Voice
- Do major POVs still sound different?
- Is prose becoming uniformly poetic or uniformly banter-heavy?
- Are metaphor domains and ending forms repeating?
- Has retrospective narration become a tic?

### Replan rule

Do not silently rewrite book direction.
Produce:
- evidence;
- affected ledgers;
- proposed changes;
- protected things not to change;
- human approval requirement.


## Ensemble Character Life
- Are Tier A/B characters still living independent lives?
- Did anyone return from a long absence unchanged without reason?
- Do supporting-character relationships exist without the protagonist?
- Did Tier C volume characters receive an actual life consequence?
- Is a side plot present only to prove "independence" without affecting character or story?

Run `workflows/character-life-audit.md`.

## Project asset consistency
If architecture or canon changes materially:
- identify publication / visual assets derived from old canon;
- mark affected assets stale;
- do not silently keep inconsistent cover/synopsis promises.
