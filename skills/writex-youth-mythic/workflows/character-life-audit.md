# Character Life Audit

Run after the base continuity audit.

## 1. Tier review
List all active characters and confirm A/B/C/D tier.

Do not over-promote minor characters.

## 2. Remove-Protagonist Test
For each Tier A/B/C:
- what did they want during this period?
- what happened if the protagonist is removed from the summary?
- what independent choice did they make?
- what changed in their life?

If the summary collapses, flag `protagonist_orbiting_character`.

## 3. Offscreen Life Clock
For every Tier A/B character absent for a meaningful interval:
- did job / family / money / routine / relationship / ambition change?
- if not, is stability explicitly plausible?

Flag `frozen_supporting_life` only when the freeze feels artificial.

## 4. Relationship graph
Check whether important supporting characters have meaningful relations with anyone besides the protagonist.

A cast should not be:
`everyone -> protagonist`.

## 5. Volume guest closure
Every Tier C volume character should end with:
- changed life;
- changed relationship;
- accepted / rejected goal;
- departure;
- survival cost;
- death;
- or another explicit consequence.

## 6. Filler guard
Do not add a side plot solely to prove independence.

If a life detail does not change:
- characterization,
- decision,
- stakes,
- relationship,
- or future re-entry,
keep it in the ledger rather than prose.
