# Build Publication & Visual Package

Prerequisite:
- approved NovelProjectCanon;
- stable first-volume promise;
- spoiler boundary.

## Publication package
Generate:
1. recommended title + alternates;
2. one-sentence hook;
3. platform synopsis;
4. long synopsis;
5. internal/editor pitch;
6. tags;
7. short promotional copy.

Run consistency gate against canon.

## Visual package
Generate:
1. Project Visual Bible;
2. cover brief;
3. major-character visual briefs;
4. volume poster briefs;
5. optional chapter / promo key-art briefs.

Every brief declares:
- canon version;
- spoiler tier;
- asset purpose.

## External handoff
When a user-selected visual skill exists:
- send the brief;
- keep returned asset metadata;
- do not merge visual skill rules into the writing engine.

## Revisions
If canon changes:
- publication copy: regenerate affected sections;
- visual assets: mark stale if their dependencies changed;
- unaffected assets stay active.
