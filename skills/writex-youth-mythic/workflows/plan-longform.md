# Enhanced Plan Longform

Always execute WriteX Base long-form planning first.

## Volume extension

For each volume, add a compact `ReaderDrivePlan`:

- local reader question;
- personal lack;
- world crack;
- 1–3 secondary reader questions;
- attachment targets;
- normality reservoir targets;
- major character magnetism beats;
- core relationship asymmetry;
- optional mystery/type payoff ladder;
- emotional debt timing;
- climax convergence channels;
- local closure;
- cross-volume handoff.

### Required discipline

Do not turn every field into a separate subplot.

A single event may satisfy several fields.
Example: a family dinner can simultaneously:
- deposit normality;
- reveal a character's ordinary desire;
- shift a relationship boundary;
- seed an afterimage carrier.

## Sequence extension

A 3–8 chapter sequence should explicitly state:
- which existing reader question narrows or pays;
- which character understanding changes;
- which relationship changes state;
- which type payoff is due, if any;
- which emotional debt is deposited/touched/released;
- which promises remain protected.

Do not detail line-level prose this far out.


## Ensemble extension

For each volume, include:
- which Tier A/B life arcs progress even if the protagonist is absent;
- Tier C guest-character life arc and post-volume consequence;
- planned offscreen changes;
- non-protagonist relationship changes;
- cast ending-state obligations.

Cross-volume foreshadowing should include both plot promises and life promises.

Example:
- "mentor plans to transfer to day shift" can later affect availability, family scenes, and emotional stakes without being a mystery clue.
