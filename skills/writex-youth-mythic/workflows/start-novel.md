For publishable new-book projects, prefer `workflows/launch-novel-project.md`.

# Enhanced Start Novel

Use WriteX Base to establish:
- perennial human question;
- character shame/desire/self-deception;
- impossible choice;
- specific life situation;
- literary release plan.

Then add only the minimum enhanced scaffolding.

## Main character
Define:
- desired reader emotion;
- fantasy value;
- private deficit;
- why power cannot solve it;
- ordinary anchor;
- independent desire;
- recognition mismatch, if relevant;
- one loss target.

## Core relationship
Define:
- A wants from B;
- B wants from A;
- actual offers;
- durable asymmetry;
- mutual truth;
- boundary.

## Reader drive
Define:
- one primary work-level reader question;
- one volume-level question;
- optional mystery question only if the premise naturally contains one.

## Language
Define a voice profile for each major POV:
- lexical / knowledge domains;
- humor defense;
- metaphor sources;
- stress-language shift;
- things this character would never think/say.

Do not select a large pattern bundle at story start.
Patterns emerge from the story's needs.


## Supporting cast setup
Before architecture approval:
- assign A/B/C/D tiers;
- create Life Contracts for Tier A/B;
- outline Volume Life Arcs for planned Tier C characters;
- define at least one non-protagonist relationship for each Tier A/B character.
