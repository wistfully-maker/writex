# Enhancement Router

Load WriteX Base first. Then activate only what the current planning/drafting step needs.

## Volume planning
Always activate:
- Reader Drive.

Activate if relevant:
- Character Magnetism for major cast entry/refresh rhythm;
- Relationship Tension for core relationship arc;
- Type Pleasure for speculative/mystery/ability-heavy volume;
- Emotional Orchestration for protected loss/debt timing;
- Adaptive Prose only to define broad language evolution, not line-level prose.

## Sequence planning
Activate:
- Reader Drive.
- any layer with a scheduled state change inside the sequence.

A sequence plan should state:
- which reader questions move;
- which character understanding refreshes;
- which relationship state changes;
- which mystery is narrowed/paid;
- which emotional debt is deposited/touched/released;
- which prose modes are likely, without locking sentence-level choices.

## Chapter planning
Start from ChapterIntent + continuity + long-form directive.

Build an `EnhancementBundle` with only active fields.

### Reader Drive activation triggers
- chapter plants, narrows, pays, or transforms a reader question;
- chapter changes external/private pressure;
- chapter contains local payoff or ending handoff.

### Character Magnetism triggers
- major character introduction;
- competence proof;
- vulnerability crack;
- independent agency;
- costly choice;
- relationship reframe;
- refresh is overdue.

### Relationship Tension triggers
- relationship-critical dialogue;
- secret pressure;
- sacrifice/protection;
- boundary change;
- rupture;
- repair;
- relationship-definition change.

### Type Pleasure triggers
- mystery move;
- identity reveal;
- competence/power payoff;
- world rule reveal;
- epistemic threat;
- false objective transition.

### Emotional Orchestration triggers
- ordinary-life deposit for later loss;
- loss shadow;
- impact;
- functional numbness;
- afterimage touch/release;
- grief/recognition/guilt/moral injury state change.

### Adaptive Prose
Always active at drafting, but load only one primary scene mode plus optional secondary mode.

## Foreground budget

Per scene:
- default max foreground enhancement modules: 2;
- hard max: 3 for true convergence/climax scenes.

Example:
- ordinary banter scene: Character Magnetism + Relationship Tension; prose mode = banter.
- reveal scene: Type Pleasure + Relationship Tension; prose mode = lore/reveal.
- aftermath scene: Emotional Orchestration + Character Magnetism; prose mode = quiet emotional.
- climax: Relationship + Type Pleasure + Emotion may all foreground, but prose must become simpler, not more ornate.

## Stop rule

If the chapter requires 4–6 modules to be "the main point" simultaneously, the scene or chapter is likely overloaded. Split or reprioritize.


## Ensemble Character Life triggers
Activate when:
- a Tier A/B recurring character enters a volume plan;
- a volume introduces a Tier C guest character;
- a recurring character returns after meaningful absence;
- a supporting character's life intersects the main plot;
- the cast begins to feel protagonist-centered.

Do not foreground 7G in every scene.
Most of its work lives in planning and ledgers.

## Project Orchestrator triggers
Activate when the user asks for:
- a new publishable novel project;
- whole-book architecture;
- title / synopsis / tags / pitch;
- cover / poster / character visual planning;
- release package;
- coordination between writing and visual skills.
