# Publishing Package

All outputs derive from approved NovelProjectCanon.

## Required launch artifacts

### Title set
- recommended title;
- 5–15 alternates when requested;
- title promise;
- ambiguity / discoverability notes;
- platform-fit rationale.

### One-sentence hook
Must contain:
- protagonist abnormal advantage or premise;
- meaningful cost / contradiction;
- concrete private stake when possible.

### Platform synopsis
Recommended structure:
1. immediate world crack;
2. protagonist's unique ability / situation;
3. cost;
4. private goal;
5. first large mystery / promise.

Do not summarize the entire book.

### Long synopsis
500–1500 Chinese characters as appropriate:
- premise;
- main character;
- initial arc;
- book-level direction;
- tone;
- no prose excerpt imitation.

### Editor / internal pitch
Include:
- genre;
- target reader;
- one-sentence hook;
- differentiation;
- first three chapters;
- first volume;
- long-term progression;
- emotional engine;
- length;
- update / production plan if known.

### Tags / keywords
Use only tags supported by the actual project.
Do not add high-traffic tags that contradict the book.

### Promotional copy pack
Optional:
- 15-character;
- 30-character;
- 50-character;
- 100-character;
- character quotes written as original marketing copy, not source imitation.

---

## Consistency gate

Publication copy must not:
- promise harem if the book is single-romance;
- promise pure high-power action if the book is investigation-heavy;
- expose author-only mystery;
- invent a power the protagonist does not have;
- imply a tone the prose does not sustain.

Marketing is allowed to compress.
It is not allowed to lie about the reading experience.
