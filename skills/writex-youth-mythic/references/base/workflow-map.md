# Workflow Map

## State-first routing

Before creating anything, determine which artifacts already exist.

| Current state | Next legal action |
| --- | --- |
| Only user seed | establish literary core and long-form intent |
| Literary core + intent, no book plan | create book plan |
| Book plan, missing current volume plan | create current volume plan |
| Long-form plan, no current rolling horizon | create rolling-horizon plan |
| Next chapter has no intent | compile continuity + structural directive into chapter intent |
| Chapter intent only | emotional diagnosis -> chapter contract -> scene plan -> technique plan |
| Plans complete | three drafts -> anonymous reviews -> select/revise |
| Candidate passes literary review | chapter-level review -> state diff |
| Ready chapter | ask for human acceptance |
| Human accepted | produce ChapterAcceptance -> continuity extract -> ledger update -> risk scan |
| Five accepted chapters | long-range audit |
| High/veto risk or material story growth | long-form replan proposal -> human approval |

## Never skip these human gates

1. Story kernel / major cast direction.
2. Book and volume direction when materially established or replanned.
3. Every final manuscript chapter before canonical acceptance.
