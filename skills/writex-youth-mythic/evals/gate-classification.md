# Gate Classification

## Base invariants: always hard
- POV secret legality.
- Canon / continuity consistency.
- Explicit human chapter acceptance before canonical commit.
- Explicit human approval for long-range replan.
- Protected book promises cannot be paid early.

## Enhanced hard gates: explicit contract invariants
- volume cliffhanger requires prior local closure;
- reveal must declare a concrete consequence;
- major relationship repair must record a repair cost;
- afterimage release must reference a previously seeded carrier;
- power/competence payoff must declare constraint or cost;
- major relationship event must declare state change;
- mystery reveal cannot be created by hiding facts the current POV explicitly knows.

## Enhanced quality gates: agent-evaluated
- enough normality before tragedy;
- character magnetism refresh is meaningful;
- supporting character agency is real;
- relationship asymmetry cannot be fixed by one low-cost conversation;
- type payoff feels earned rather than power creep;
- emotional release matches character psychology;
- prose sounds owned by POV;
- description and metaphor are selective rather than ornamental.

## Patterns: optional
No pattern is required merely because it was present in the research corpus.

The pattern library is a toolbox, not a recipe.


## Stage 7G hard gates
- Tier A/B requires at least one non-protagonist relationship.
- Tier B requires an Offscreen Life Clock.
- Tier C requires a post-volume consequence.
- Tier A/B requires an explicit ending state in book architecture.

## Stage 7G quality gates
- Remove-Protagonist Test.
- Ordinary life specificity.
- Supporting-character agency.
- Offscreen changes are causal.
- Relationship graph is not only protagonist-centered.

## Stage 8 project hard gates
- Project-mode drafting requires human architecture approval.
- Publishing/visual artifacts reference canon version.
- Public assets obey spoiler boundary.
- Marketing copy cannot invent canon.
